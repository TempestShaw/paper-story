# Claim–evidence ledger

Preserve one row per material assertion. Split a sentence that bundles multiple kinds of claims. Keep the exact scope even after an item becomes VERIFIED.

Statuses: VERIFIED = inspected support for the bounded claim; REPORTED = attributed statement without underlying artifact checked; HYPOTHESIS = proposed explanation/prediction; PLANNED = work not completed; CONTRADICTED = available evidence conflicts; UNKNOWN = insufficient information.

## Quantitative checks

Record the metric definition and direction, units, numerator/denominator, independent sampling unit, sample size, number of runs, aggregate method, comparison budget, and source of uncertainty. Use “unknown” for unavailable information; do not infer it from a leaderboard number.

## Provenance and search notes

Record which underlying artifacts were inspected, which facts came only from the user, source access dates when relevant, novelty-search boundaries, and unresolved citation metadata. Preserve negative findings and changes to the original interpretation.
